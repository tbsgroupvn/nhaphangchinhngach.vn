# TBS Studio Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans and the TDD workflow. Keep progress in this file; do not mark the overall goal complete at an intermediate milestone.

**Goal:** A complete, secure website CMS with integrated SEO and AI workflows, connected to the actual public website.
**Architecture:** Persistent SQLite repositories and independently protected Next route handlers; a shared operational admin shell and typed editors; published-only public adapters. Existing marketing visuals and no-form constraints stay intact.
**Tech Stack:** Existing Next.js 14/React 18/TypeScript, Heroicons, Zod, SQLite, Node crypto and provider HTTP APIs.
**Spec:** `docs/superpowers/specs/2026-09-26-tbs-studio-design.md`.

## Global Constraints

No live deployment or commits. Preserve unrelated changes. Database/media/secrets stay outside public and Git. No demo authorization or fake AI/analytics. No public lead forms. Indexing stays off. All admin mutations validate origin, session, role, input and revision where applicable. Use existing logo palette and operational UI, not marketing composition.

## Review Focus

- A draft update must not leak to public content; pin with before/after publish HTTP tests.
- Two editors must get a 409 instead of lost edits; pin with parallel expected-version saves.
- Revoked/disabled users and forged client roles must fail on direct API requests.
- AI malformed responses/timeouts and missing credentials must never create a successful job or apply unreviewed content.
- Media and redirect inputs must reject traversal, active content, unsafe destinations and redirect loops.
